## 说明

node 下的 BrowserSync 可以实现监视文件变动然后自动刷新浏览器；

Browsersync 中文网 - 省时的浏览器同步测试工具

[http://www.browsersync.cn/](<http://www.browsersync.cn/> "Browsersync中文网 - 省时的浏览器同步测试工具")

----

本插件可以帮你拼接相应的命令供复制执行；

会在 `http://localhost:3000` 上开启一个新的服务来反代开发站点，文件有修改会自动刷新，可以登录后台，<span style="text-decoration: line-through;">但是 csrf 相关的操作会失败</span> 好像需要关掉「安全增强」- -；
